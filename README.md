# Cybersecurity Homelab

A hands-on cybersecurity homelab built to develop practical experience in networking, system administration, security monitoring, vulnerability assessment, and incident response.

This repository documents the development of my lab environment, the tools I configure, security exercises I perform, problems I encounter, and what I learn while working toward a career in cybersecurity.

## Current Lab Environment

### Host System
- Windows 10 Home
- Intel Core i3-8100
- Intel UHD Graphics 630
- 4 TB SSD
- Oracle VirtualBox

### Virtualization Environment

Oracle VirtualBox is used to create and manage isolated virtual machines for cybersecurity testing, system administration, networking, and security monitoring.

### Virtual Machines

#### Ubuntu Server
- Ubuntu Server running as a VirtualBox virtual machine
- SSH configured for remote administration
- Network connectivity established with the lab network
- Used as the first Linux server in the cybersecurity environment
